# Minutes Templates

## Header (all types)
**[Meeting title]** · [date, time, time zone] · [location / call link]
Attendees: … · Apologies: … · Prepared by: …

## Steering committee / client update
1. Headline (one sentence)
2. Decisions (numbered, "Agreed: …", who agreed)
3. Approvals given / pending (gate, status)
4. Action items (table: #, action, owner, due, source)
5. Risks & escalations
6. Discussion summary (short, by agenda item)
7. Next meeting

## Internal standup / PM sync
1. Progress since last time (by workstream)
2. Blockers (blocker, unblocker, owner)
3. Action items (table)
4. Next standup

## Mentor / EIR sync
1. Participants covered
2. Per participant: progress, concern level (low/med/high), mentor ask
3. Mentor delivery issues (missed sessions, SLA breaches)
4. Action items (table)

## Selection committee
1. Applicants reviewed
2. Decisions per applicant (Accept / Waitlist / Reject) with rationale
3. Borderline cases and how they were resolved
4. Open questions for verification
5. Action items (table)

## Founder / participant check-in
1. Progress vs milestones / KPIs
2. Wins
3. Blockers and support asked for
4. Commitments by the founder (action, date)
5. Commitments by the program team (action, owner, date)

## Partner / investor call
1. Interest expressed (who, in what, how strong)
2. Next steps agreed
3. Leads to log (participant, partner, type, owner, follow-up date)

## Event debrief
1. What happened vs plan
2. What worked / what didn't
3. Numbers (attendance, submissions, leads)
4. Follow-ups (table)
5. Changes for next time
