# Standard Program Base Blueprint

Trim to what the program needs. Hackathons usually need tables 1–3, 5 and 8; multi-month accelerators usually need all.

1. **Applications / Teams** — name, one-liner, sector, stage, source (open call / referral / partner), founders (link Contacts), status (Applied → Screened → Shortlisted → Interviewed → DD → Accepted / Waitlisted / Rejected), gate results, criterion scores, composite (formula), decision, decision date, rationale.
2. **Contacts** — person, role (founder / mentor / judge / partner / client), organisation, email, phone, linked team.
3. **Program Agenda / Sessions** — session title, type (workshop / 1:1 / office hours / fireside / pitch / event), date & time, week #, phase, lead (link Contacts), attendees, materials link.
4. **Mentors / EIRs** — profile, sectors, expertise tags, availability, interview scores, status (Longlist → Interviewed → Shortlisted → Onboarded), SLA signed.
5. **Matches** — mentor ↔ team, rationale, start date, sessions delivered (rollup), satisfaction trend.
6. **Session Log** — match, session #, date, agenda, actions agreed, next session date.
7. **KPIs** — team, KPI name, baseline, target, checkpoint values, % to target (formula).
8. **Feedback** — session/workshop pulse (overall 1–5, takeaway, recommend Y/N, blockers), full workshop survey, mentor-session pulse; reviewer + reviewed date for SLA.
9. **Judging** (events) — judge, team, round, criterion scores, comments, total (formula).
10. **Partners & Leads** — investor/corporate, interest type, linked team, owner, follow-up status, next step date.
11. **Sourcing Leads** — organisation, website, sector, stage signal, location, fit (Strong/Possible/Weak) + reason, source link, contact route, channel, owner, status (Not contacted → Contacted → Replied → Applied / Declined), do-not-contact flag, linked application.
