# Mentor Framework

## Matching factors (score each 1–5 per participant × mentor)

| Factor | Default weight | What fits looks like |
|---|---|---|
| Need–expertise fit | 35% | Mentor has solved the participant's top 1–2 growth gaps before |
| Sector / technology familiarity | 20% | Worked in or sold into the same vertical |
| Stage fit | 15% | Has operated or advised at the participant's stage and the next one |
| Market / geography access | 15% | Network in the participant's target market or buyer type |
| Working-style fit | 10% | Coaching style suits the founders (directive vs facilitative; language; availability windows) |
| Capacity | 5% | Mentor has room within their commitment |

Hard constraints (override scores): conflicts of interest, mentor capacity reached, language mismatch, participant explicitly declines.

## Typical commitments (replace with the program's own)

- Minimum sessions per participant per month: 2
- Response time to participant messages: < 24 hours on working days
- Session logging: within 48 hours, with at least one owned, dated action
- Satisfaction pulse: after every 2nd session; PM review within 48 hours

## Status definitions

- **On track:** meets session minimum, next session booked, no SLA breach, latest pulse ≥ 3.5/5
- **At risk:** one session short, nothing booked in the next 14 days, or a single pulse ≤ 3/5
- **Off track:** two or more sessions short, SLA breached, two consecutive pulse drops, or any pulse ≤ 2/5

## Onboarding sequence

1. Engagement brief and availability confirmation
2. Interview and scoring
3. Shortlist approval (client/committee)
4. Engagement agreement / SLA signed
5. Onboarding pack + orientation session
6. Chemistry/intro session with matched participants
7. First session using the diagnostic agenda; tracker set up with the participant
