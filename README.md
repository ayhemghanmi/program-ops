# Program Ops

Six skills for running any startup or innovation program. They are program-agnostic: each one reads a short **program profile** (dates, cohort, governance, rubric, tools, brand) from the current project, or builds one from the program's documents and asks you to confirm the gaps.

| Skill | What it does |
|---|---|
| program-agent | Sets up the program profile; reads/updates the mastersheet and Gantt; overdue items, approvals, week plans, run-of-shows, go/no-go checks |
| report-agent | Weekly emails, client updates, steering committee reports, checkpoint reviews, post-event and impact reports |
| scoring-agent | Gate checks, weighted scoring, judging tallies, reviewer calibration, shortlists; rubric library for new programs |
| airtable-agent | Safe reads, confirmed writes, building a program base from a standard blueprint, automations |
| presentation-agent | Kickoff, report, committee, workshop, demo day, proposal and close-out decks in the client's brand |
| humaniser-agent | Final pass that removes AI tells and matches tone, without changing facts |

Start a new program with: "set up a new program" (program-agent). Save the resulting program-profile.md in that program's project.

Connectors used when available: Airtable, Gmail, Google Drive, Fireflies.
